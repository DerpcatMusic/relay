# relay-protocol

Rust consumer for the `relay.v1` Protobuf contract.

`src/generated/relay.v1.rs` is checked in so consumers do not need `protoc`,
Buf, or a network connection at build time. It is generated by the pinned
remote plugin in `proto/buf.gen.yaml` and must never be edited by hand.

From the repository root, regenerate all protocol consumers with:

```sh
cd proto
npx --yes @bufbuild/buf@1.57.2 generate
```

Review generated diffs, then run this crate's isolated tests:

```sh
cargo test --manifest-path crates/relay-protocol/Cargo.toml --locked
```
