# @relay/protocol

TypeScript consumer for the `relay.v1` Protobuf contract.

`src/generated` is checked in so consumers do not need Buf or a network
connection at build time. Every file in that directory is generated by the
pinned `protobuf-es` remote plugin in `proto/buf.gen.yaml`; never edit generated
files by hand.

From the repository root, regenerate both Rust and TypeScript consumers with:

```sh
cd proto
npx --yes @bufbuild/buf@1.57.2 generate
```

The template requests `.js` import specifiers so emitted Node ESM remains
loadable while TypeScript resolves the checked-in `.ts` sources.
