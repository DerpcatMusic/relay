# Task research records

Every implementation task must add one focused Markdown record here containing:

1. Task scope and acceptance criteria.
2. Sources consulted (primary/upstream sources preferred; include access date).
3. Findings relevant to the implementation.
4. Potential corrections to the master plan, including “none” when appropriate.
5. Decisions applied and validation evidence.

Research is part of the task definition, not optional follow-up work.
